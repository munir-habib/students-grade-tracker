# Changelog

## v0.1.0 (2026-10-11)
First tagged version, built on 2026-08-31.
- MVP: courses, terms, assessments, grade calculation (categories and points), GPA on the 0 to 4.0 scale and grade simulator.
- Syllabus import with an Edge Function that uses the Anthropic API (needs an `ANTHROPIC_API_KEY` secret to run end to end).
- English, Portuguese and Hindi interface; responsive sidebar for mobile and tablet; SPA routing on Vercel.
- Onboarding script to populate real student accounts from Excel templates.

A full copy of the repository at this point is kept in the branch `backup/2026-10-11`.
